# Sales Data Visualization & Storytelling Dashboard

## Project Overview

This project focuses on analyzing sales data and presenting meaningful business insights through an interactive Power BI dashboard.

## Objective

To visualize sales performance across different regions and help understand business performance through data storytelling.

## Tools Used

* Power BI
* Microsoft Excel
* CSV Dataset

## Power BI Dashboard

![Sales Data Visualization & Storytelling Dashboard](.png)       Power BI Dashboard
  
## Dashboard Features

* Sales performance analysis
* Regional sales comparison
* Customer and order analysis
* Interactive data visualization
* Key business insights

## Key Insights

* West region generated the highest sales.
* South region generated the lowest sales.
* East and Central regions showed moderate sales performance.
* West was the strongest-performing region, while South needs improvement.

## Business Recommendation

Focus on improving sales performance in the South region and maintain the strong performance of the West region.

## Conclusion

This project demonstrates data visualization, analytical thinking, and business storytelling using Power BI.
